# NexaCRM

ERP / CRM solution for invoicing, payments, quotes, and customer management.

Built with Node.js, React, MongoDB, and Ant Design.

## Requirements

- Node.js 20.9.0+
- MongoDB

## Setup

### Backend

```bash
cd backend
npm install
# Configure .env with your DATABASE and JWT_SECRET
npm run setup
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Backend runs on `http://localhost:8888`, frontend on `http://localhost:3000`.
